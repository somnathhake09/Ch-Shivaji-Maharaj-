# 🏰 Chhatrapati Shivaji Maharaj – Historical Website

An attractive, modern and fully responsive website based on the life, history and legacy of Chhatrapati Shivaji Maharaj.

---

## 🌐 Live Website

👉 https://somnathhake09.github.io/Ch-Shivaji-Maharaj-/

---

## 📖 About The Project

This website presents the inspiring journey of Chhatrapati Shivaji Maharaj in a visually engaging way, including:

* 👶 Childhood and early life
* ⚔️ Establishment of Swarajya
* 🏯 Famous forts (Raigad, Pratapgad, Sinhagad, Shivneri)
* 📜 Historical timeline
* 🖼️ Image gallery
* 💬 Inspirational quotes
